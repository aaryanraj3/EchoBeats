# EchoBeats - MERN Stack Music Streaming Platform

## TEAM RAVEN PROJECT

EchoBeats is a full-stack music streaming web application built using the MERN stack. The platform allows users to explore, play, and manage music through a clean and user-friendly interface.

This project demonstrates the use of modern web development technologies such as React.js, Node.js, Express.js, MongoDB, and Tailwind CSS to build a real-world music streaming platform.

## Live Website

Website Link: https://echobeats-14jw.onrender.com/

## Project Overview

EchoBeats is designed as a simple and interactive music streaming platform where users can listen to songs, manage playlists, and experience a responsive music player interface.

The project focuses on building a scalable full-stack application with authentication, playlist management, music playback features, and a secure backend connected with MongoDB.

## Key Features

* User authentication and authorization
* User-friendly music streaming interface
* Create and manage playlists
* Play, pause, and control music
* Responsive frontend design
* Secure backend using Node.js and Express.js
* MongoDB database integration
* MERN stack-based full-stack architecture

## MERN Stack Architecture

```text
Frontend: React.js + Tailwind CSS
        ↓
Backend API: Node.js + Express.js
        ↓
Database: MongoDB
        ↓
Deployment: Render
```

## Project Workflow

```text
User opens EchoBeats
        ↓
User signs in / accesses platform
        ↓
User explores available music
        ↓
User plays and controls songs
        ↓
User creates or manages playlists
        ↓
Data is handled through backend APIs
        ↓
MongoDB stores user and playlist-related data
```

## How to Run the Project Locally

Follow these steps to run EchoBeats on your local system.

### Step 1: Clone the Repository

```bash
git clone https://github.com/aaryanraj3/EchoBeats.git
```

### Step 2: Open the Project Folder

```bash
cd EchoBeats
```

### Step 3: Install Root Dependencies

```bash
npm install
```

### Step 4: Setup Frontend

```bash
cd frontend
npm install
```

### Step 5: Run Frontend

```bash
npm run dev
```

### Step 6: Setup Backend

Open a new terminal and run:

```bash
cd backend
npm install
```

### Step 7: Run Backend

```bash
npm start
```

If the backend uses a development script, run:

```bash
npm run dev
```

## Environment Variables

If the project uses environment variables, create a `.env` file inside the backend folder and add required values such as:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
PORT=5000
```

Do not upload `.env` files to GitHub.
